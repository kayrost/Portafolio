Sobre Mí

«Junior por hoy, pero con aspiraciones firmes a dominar nuevos lenguajes, frameworks y crecer tanto en el ámbito laboral como en el personal.»

Mi nombre es Santiago Higuera. Soy un desarrollador junior enfocado en el desarrollo web frontend y estudiante apasionado de Ingeniería en Sistemas. Me fascina entender cómo funcionan las cosas por debajo: desde la semántica estructurada de la web hasta la interactividad dinámica y la lógica algorítmica.

Actualmente me dedico a afianzar al máximo las bases nativas de la web (HTML5, CSS3 y JavaScript), asegurando que cada proyecto que realizo sea rápido, responsive, accesible y visualmente agradable en cualquier dispositivo.

Habilidades Técnicas

Las 3 tecnologías fundamentales que domino y aplico activamente en mis desarrollos:

Estructura & Semántica

HTML5

Base estructural de toda aplicación web moderna. Enfoque en código semántico para maximizar accesibilidad (a11y) y posicionamiento SEO orgánico.

  • ✓ Etiquetas Semánticas (header, main, section, nav)
  • ✓ Formularios modernos con validación nativa
  • ✓ Buenas prácticas de Accesibilidad (ARIA)
  • ✓ Metaetiquetas y Open Graph para compartir
Estilos & Maquetación

CSS3

Creación de interfaces limpias, estéticas y completamente responsivas. Dominio de sistemas de layout modernos, variables y efectos visuales fluidos.

  • ✓ Flexbox & CSS Grid multidimensional
  • ✓ Media Queries y enfoque Mobile-First
  • ✓ Variables CSS (Custom Properties) & Temas
  • ✓ Transiciones, Keyframe Animations & Glassmorphism
Lógica & Dinamismo

JavaScript (ES6+)

El motor interactivo de la web moderna. Manipulación reactiva del DOM, captura de eventos, asincronía y control de flujo para dar vida a la interfaz.

  • ✓ Manipulación dinámica del DOM & Listeners
  • ✓ ES6+ (Arrow functions, Destructuring, Template literals)
  • ✓ Asincronía: Fetch API, Promesas & Async/Await
  • ✓ Validación de formularios y LocalStorage

Mis Creaciones

Proyectos Destacados

Aplicando los conceptos de HTML, CSS y JavaScript en soluciones reales e interactivas:

Portafolio Web Profesional v2.0

Rediseño integral de mi portafolio aplicando las mejores convenciones de diseño web moderno: maquetación semántica, paleta Obsidian & Gold, diseño 100% responsivo para móviles y microinteracciones fluidas.

HTML5 CSS3 Grid/Flex JavaScript ES6+ Glassmorphism

TaskFlow Pro - Gestor de Metas

Aplicación web interactiva que permite crear, filtrar, editar y persistir tareas en el navegador. Demuestra manipulación avanzada del DOM, eventos personalizados y sincronización con LocalStorage.

JavaScript ES6 DOM API LocalStorage Filtros Reactivos

DevMetrics - Utilidad de Conversión

Herramienta de cálculo y conversión instantánea para desarrolladores frontend: unidades px a rem/em, cálculo de contrastes de color WCAG y estimador de tiempos de lectura de contenido.

JavaScript Lógico CSS Variables Validación en Vivo UI Limpia
